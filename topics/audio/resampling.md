# 音频重采样 / SpeexDSP

- 别名与生态：音频重采样 / SpeexDSP
- 适用版本与平台：见使用步骤和示例依赖；不继承历史工程版本
- 标签：audio
- 示例状态：新示例；需要外部开发库/环境，未编译或联调
- 代码来源：为本手册新写；不引用 2016Codes 代码

## 是什么

重采样将离散音频转换为另一采样率，同时尽量保持播放时长和音调。它需要插值及适当的抗混叠滤波，不是修改文件头或简单丢弃数据。SpeexDSP 提供有状态的重采样器，与 Speex 语音编解码器应区分。

## 何时使用

采集设备、识别器与播放设备要求不同采样率时使用。质量、CPU 与滤波延迟需要权衡。

## 如何使用

1. 确认输入声道布局、采样率和样本类型。
2. 用 speex_resampler_init 创建实例。
3. 每次调用传入输入可用量和输出容量。
4. 调用后按实际 consumed/produced 移动游标，保留未消费输入。
5. 持续复用状态；结束时按业务需要处理滤波尾部并销毁。

## 最小示例

以下命令均从仓库根目录运行。

[新 SpeexDSP 示例](../../examples/native/resample.c)将 320 帧 16 kHz 音频转换为 48 kHz。

```sh
cc -std=c11 examples/native/resample.c -lspeexdsp -o /tmp/resample-demo
/tmp/resample-demo
```

输出实际消费与产生的帧数，不能假定任意单次调用都恰好得到理论比例。

## 常见问题

每块重新初始化会造成边界失真。左右声道应保持独立状态或使用交错接口。降采样前需要滤波；有限块输出还受延迟和缓冲影响。
