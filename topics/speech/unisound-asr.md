- 代码来源：为本手册独立新写；教学源码见本仓库 examples/

## 是什么

ASR 把音频转换为文本。云知声 SDK 属于具体厂商产品，鉴权、会话接口及结果生命周期依开发包版本而变，不能把旧 libusc 调用假定为当前通用 API。

## 何时使用

已获得对应服务权限、许可和开发包的应用。接入应区分 SDK 错误、网络错误、部分结果和最终结果。

## 如何使用

1. 核对 SDK 平台/ABI、版本、服务权限和输入音频要求。
2. 在 adapter 内初始化、鉴权并开始会话。
3. 顺序送入 PCM，按返回码处理反压或错误。
4. 通知输入结束并等待有界的最终结果。
5. 在成功和失败路径上都释放会话。

## 常见问题

不要将凭证写入仓库。输出缓冲可能在下一次回调后失效；应按 SDK 所有权规则复制。输入结束不一定表示结果立即就绪，adapter 应封装等待机制。
