# 关键词唤醒 / Wake Word

- 别名与生态：关键词唤醒 / Wake Word
- 适用版本与平台：见使用步骤和示例依赖；不继承历史工程版本
- 标签：speech
- 示例状态：接入契约，非 SDK 实现；需要实际模型与开发包
- 代码来源：为本手册新写；不引用 2016Codes 代码

## 是什么

关键词唤醒模型检测预设词或短语，与 VAD 检测“有无语音”和 ASR 识别全文不同。模型通常要求固定采样率、窗口与连续状态。

## 何时使用

低功耗语音入口、启动后续识别流程。模型、阈值与麦克风环境决定漏唤醒和误唤醒表现。

## 如何使用

1. 取得目标 SDK 和兼容模型，确认许可与平台。
2. 初始化模型并配置音频格式。
3. 持续输入完整音频帧，读取分数或事件。
4. 唤醒后切换录音/识别状态，设置冷却和重置策略。
5. 释放模型和设备资源。

## 常见问题

不能用平均能量替代关键词模型。训练/推理格式必须一致；处理回调线程和音频线程的并发。模型版本与初始化参数不能凭旧接口名称猜测。
