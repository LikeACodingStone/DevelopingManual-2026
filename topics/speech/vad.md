# VAD：语音活动检测

- 别名与生态：VAD：语音活动检测
- 适用版本与平台：见使用步骤和示例依赖；不继承历史工程版本
- 标签：speech
- 示例状态：新能量门控已离线验证；Huwen 专有 SDK 不复用、不声称集成
- 代码来源：为本手册新写；不引用 2016Codes 代码

## 是什么

VAD 判断一段音频中是否存在语音，常用来确定送入识别器的起止位置。能量阈值只能区分较强/较弱信号，不能可靠区分人声和噪声。

## 何时使用

语音端点检测、节约识别流量和录音切段。一般按固定时长分帧，并结合开始阈值、结束阈值及 hangover 防止频繁抖动。

## 如何使用

1. 确认单声道采样率和每帧样本数。
2. 计算特征或调用真实 VAD 模型。
3. 维护 silence/start/active/end 状态。
4. 根据允许的尾部静音长度结束片段，必要时保留预录音缓冲。

## 最小示例

以下命令均从仓库根目录运行。

[新能量门控示例](../../examples/python/vad.py)仅展示状态机，不是 Huwen SDK 或语音分类器。

```sh
python3 examples/python/vad.py
```

预期 `silence start active active end`。

## 常见问题

阈值取决于归一化方式和输入幅度。固定帧长下 hangover×帧时长才是等待时间。背景音乐也能触发能量门控；生产需求应选真实 VAD 并评估噪声条件。
